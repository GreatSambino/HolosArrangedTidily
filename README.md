# Holos Arranged Tidily

Made as the foundation for a fan-game that rather blatantly copied another game "Cats Organized Neatly", but with a Hololive theme.

The gameplay is simple, you are given a puzzle grid and several pieces which you can rotate and place into the grid, with the goal of filling every empty grid space to solve the puzzle.
This project implements the basic gameplay elements of moving and rotating pieces, and includes a level editor and gallery to view the various puzzle pieces.
A core idea, again copied from Cats Organized Neatly, is that different shaped puzzle pieces have unique art, hence the gallery. The idea of the fan game was that each piece would be created by a different artist and would be a reference to Hololive.

This project might be a useful starting point for someone looking to create their own "Cats Organized Neatly"-style game.

This was my first time coding in gdscript after switching from Unity to Godot, so may contain some rough edges.
